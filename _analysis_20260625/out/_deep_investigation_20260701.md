## 追補: メタ注釈の解消 2026-07-01 (2×字数ルール遵守)
ユーザー指針「メタ的注釈は2×字数を超えるため非推奨」に対応。
- 対象: kred/it系(信用/credit)6語 + komand/it/ant(合資) の it断片メタ注釈(「(信用語根の一部)」等、各言語7エントリ)。
- 処理: 偽分解の2断片に1字ずつ配分し、組み合わせて正しく読めるよう是正(非メタ・各≤2×字数):
  kred 信用→信 + it (メタ)→用 = 信用(credit) / komand 合資→合 + it→資 = 合資(partnership)。ZH 信+用/合+资、KO 신+용/합+자。
- kred/komand のデフォルト(信じる30/指揮9)は不変。該当語のみ per-gloss で是正。
- 適用: word_anno 15×3 / deployed 221×3(<br>対応)。検証: メタ注釈残0、komanditant=合資する人、サイズ整合0不整合。backup .bak_preMeta。
